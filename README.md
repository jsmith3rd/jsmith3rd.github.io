## Tech Stack

This site is built with:

- **Vue 3** — Modern reactive UI framework
- **TypeScript** — Type-safe development
- **Vite** — Lightning-fast build tool
- **vanilla-cookieconsent** — Consent banner and preferences management
- **vue-gtag** — Google Analytics integration with consent-aware gating
- **CSS** — Custom styling with a dark glassmorphism aesthetic
